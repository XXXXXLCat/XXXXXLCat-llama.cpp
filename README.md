# XXXXXLCat-llama.cpp

基于 Tauri 2 的 **llama.cpp 桌面启动器**。以图形界面可视化配置 `llama-server` 参数、一键启动 / 停止本地推理服务、查看运行日志并打开内置 Web UI，免去记忆命令行参数的负担。

## 环境准备

| 项目 | 说明 |
| --- | --- |
| 系统 | Windows 10 / 11（需 WebView2 运行时，Win11 通常已内置） |
| 推理引擎 | llama.cpp 官方 `llama-server.exe`（本工具**不内置**，需自行准备） |
| 模型 | 至少一个 GGUF 格式模型文件 |

## 安装

前往 GitHub Releases 下载 `XXXXXLCat-llama.cpp.exe`，双击即可运行。便携版，**无需安装**，可放在任意目录。

## 快速开始

1. 打开软件，进入 **「设置」** 页，指定 `llama-server.exe` 的完整路径与模型根目录。
2. 进入 **「模型」** 页，选择主模型（视觉模型可选配 `mmproj` 投影文件）。
3. 进入 **「控制台」** 页，点击 **「启动」** 按钮，等待右上角状态徽标变为「llama.cpp 运行中」。
4. 点击 **「打开 Web UI」** 进入内置对话界面，开始推理。

## 各页面用法

### 控制台
- **启动 / 停止** 本地推理服务。
- 右上角状态徽标实时显示运行状态（未启动 / 模型加载中 / 运行中），点击徽标可快速跳回本页。
- 监听地址为 `0.0.0.0` 时，本机自动改用 `127.0.0.1` 打开 Web UI；在设置中关闭「内置 Web UI」后该按钮自动禁用。

### 模型
- 选择主模型与视觉投影 `mmproj`。
- 模型根目录可在设置中配置，选择时显示自动匹配置信度提示。

### 运行日志
- 实时滚动显示 `llama-server` 的标准输出与错误，便于排查启动失败、参数异常等问题。

### 设置
- **服务监听**：host / port。
- **推理参数**：GPU 层数、上下文长度、批大小等。
- **采样参数**：top-k / temperature / top-p / repeat-penalty / repeat-last-n / seed 等。
- **开关项**：Flash Attention、内置 Web UI。
- 每个参数旁均附有说明文字，鼠标悬停即可查看。

> 所有设置经同一套逻辑拼装为 `llama-server` 启动参数，预览与真实启动一致，所见即所得。

## 多语言

Web UI 内置界面支持 **简体中文 / 繁体中文 / 日本語 / 한국어 / English**，跟随系统语言或手动切换。

## 常见问题

- **启动失败 / 日志报错**：检查设置中 `llama-server.exe` 路径是否正确、模型文件是否完整有效。
- **整窗白屏、提示无法访问页面**：请使用从 Releases 下载的便携版 `XXXXXLCat-llama.cpp.exe`；开发调试构建需额外编译步骤，不可直接分发。
- **Web UI 打不开**：确认设置中「内置 Web UI」已开启，且服务处于「运行中」状态。
